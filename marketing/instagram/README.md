# Instagram carousel — Peak Performance Code

Ready-to-post assets for a 4-slide Instagram carousel featuring real app screenshots.

## Files

| File | Slide |
|------|--------|
| `output/01-hero.jpg` | Brand + dual-phone modules collage |
| `output/02-modules.jpg` | 10 modules grid |
| `output/03-videos-workbooks.jpg` | Videos + workbooks |
| `output/04-cta.jpg` | Download CTA |
| `output/CAPTION.txt` | Suggested caption + hashtags |

All slides are **1080×1080** (Instagram square carousel).

## Regenerate

```bash
python3 marketing/instagram/create_posts.py
```

Requires Pillow and Poppins fonts in `/tmp/fonts` (script expects `Poppins-Regular.ttf`, `Medium`, `SemiBold`, `Bold`).
